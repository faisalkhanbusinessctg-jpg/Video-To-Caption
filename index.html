STEP 01 Google AI Studio (Gemini) API Key

aistudio.google.com/apikey এ যান → Google অ্যাকাউন্ট দিয়ে লগিন করুন → "Create API Key" চাপুন → key কপি করে এখানে বসান। এটা সাধারণ API key, কোনো ক্রেডিট কার্ড/বিলিং লাগে না (ফ্রি টায়ার আছে), এবং OAuth লগিনেরও দরকার নেই। key শুধু আপনার ব্রাউজারে (localStorage) থাকে, সরাসরি Google-এর API-তে যায়, অন্য কোথাও যায় না।
লম্বা বা জটিল ভিডিও, অথবা বেশি নির্ভুল ট্রান্সক্রিপ্ট/কনটেন্ট দরকার হলে Pro বেছে নিন — খরচ ও সময় একটু বেশি লাগবে।

STEP 02 ভিডিও আপলোড

এখানে ক্লিক করে অথবা ফাইল টেনে এনে (drag & drop) ভিডিও, অডিও বা ছবি ফাইল বাছাই করুন (mp4/webm/mov/mkv, mp3/wav/m4a, jpg/png)
টিপ: ভিডিও/অডিও ৫-১০ মিনিটের ভিতরে হলে দ্রুত ও নির্ভুল রেজাল্ট পাবেন। ফাইলটি সরাসরি Google-এ আপলোড হয়ে প্রসেস হবে (আলাদা করে অডিও বের করার দরকার নেই)। ছবি দিলে ছবির বিষয়বস্তু বিশ্লেষণ করে কনটেন্ট তৈরি হবে।

বিকল্প অথবা ভিডিও ছাড়াই — টপিক/টেক্সট লিখুন

ভিডিও আপলোড করতে না চাইলে এখানে সংক্ষেপে বিষয়বস্তু লিখে দিন — সেটা বুঝে নিয়ে সরাসরি ক্যাপশন/টাইটেল/বিবরণ ও SEO তৈরি হবে। (এক্ষেত্রে সাবটাইটেল তৈরি হবে না, যেহেতু কোনো ভিডিও নেই।)
